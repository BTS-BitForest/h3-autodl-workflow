# H3 AutoDL 完整工作流

把现有 H3 面板、ComfyUI 工作流、LoRA、可选 PE、超分和 Windows 控制端一起部署到 AutoDL。包含可迁移运行环境；**这是镜像对应的部署工程，不是 AutoDL 专有镜像文件。**

## 下载与一键使用

打开 [Releases](https://github.com/BTS-BitForest/h3-autodl-workflow/releases)。公开下载，无需 GitHub 登录。

### Windows 控制电脑

1. 下载 `H3-OneClick-Windows.zip`，完整解压。
2. 双击 `一键部署-Windows.bat`，粘贴 AutoDL 的 SSH 命令，例如 `ssh -p 12345 root@your-host`。
3. 输入 SSH 密码；首次连接核对服务器指纹。新服务器会自动部署，已有镜像直接启动。
4. 新部署时无需 GitHub 授权。程序显示环境下载进度、完成 SHA256 校验，再启动模型下载并自动打开面板。

面板固定为 `http://127.0.0.1:8190/`，ComfyUI 为 `http://127.0.0.1:8188/`。请保留脚本窗口以维持 SSH 隧道。关闭窗口会断开面板连接，服务器下载和生成任务继续运行。重新运行即可连接。端口占用时会报错，不会随机换端口。

日常使用推荐下载 `H3-Windows-Launcher.zip`，完整解压并运行 `H3Launcher.exe`。这个启动器适用于**已经安装 H3 的服务器**，管理连接、可选代理及固定端口；关闭启动器会关闭它自己建立的隧道。它还有辅助文件，不能只复制 EXE。

Windows 需要自带的 OpenSSH 客户端和 Windows PowerShell 5.1 或以上。一键部署脚本与日常 EXE 是两个入口：前者能安装空白服务器，后者提供更方便的日常连接。

### Linux / AutoDL 服务器

下载 Release 附件 `deploy-linux.sh`，上传到服务器后运行：

```bash
bash deploy-linux.sh
```

程序以 root 执行，自动安装所需系统组件、下载运行环境、校验并安装，启动服务并持续打印模型下载状态。浏览器在另一台电脑时，需要用 Windows 启动器或 SSH 转发访问；不要向公网开放未加保护的 ComfyUI。

服务器没有 GPU 时可先用已安装环境的下载入口：

```bash
/opt/h3-suite/venv/bin/python /opt/h3-suite/scripts/start_download.py
python3 /opt/h3-suite/scripts/watch_download.py
```

## 租用配置

| 项目 | 要求 |
|---|---|
| 系统 | Ubuntu 22.04，Linux x86_64，root，独立挂载的 `/root/autodl-tmp` 数据盘 |
| GPU | 本版本在 RTX 4090 24GB 验证；其他型号需自行验证 |
| 驱动 | 必须支持本包 PyTorch 的 CUDA 13；实测驱动 595.71.05 |
| 系统盘 | 安装前至少空闲 20 GiB |
| 数据盘 | 安装前至少空闲 100 GiB，并另留素材、缓存和成片空间 |
| 网络 | 能访问 GitHub 获取程序；模型主要通过魔搭和 HF 镜像下载 |

基础镜像可以选 Miniconda / Ubuntu 22.04；基础镜像标注 CUDA 11.8 不会替代本包的 CUDA 13 运行库，关键是宿主 NVIDIA 驱动是否兼容。本包提供 Python 3.12.3、PyTorch 2.14.0.dev20260804+cu130 及匹配依赖，不能随意升级其中一个包。

## 内容与大小

- 全部 33 个模型与配套文件合计 **81.46 GiB**，包含 H3、视觉/文本编码器、VAE、LoRA/PDD、Qwen3.5-4B PE 和 RealESRGAN。
- Release 中已验证运行环境约 **5.2 GiB 压缩包**，Python 分卷须全部下载，程序自动拼接解压。
- 工作流、面板、启动器源代码、图标、模型固定版本与 SHA256 清单在仓库中。
- 不包含用户素材、生成视频、任务历史、登录状态和 API 密钥。DSH/Codex 附带程序与通用设置，首次使用需用户自行配置账号。

模型下载优先使用同版本魔搭文件，无对应文件时使用 HF 镜像，并保留官方源回退。使用分块续传、有限重试和最终 SHA256 校验；已完成模型不重复下载。新实例实测魔搭约 13–18 MB/s，但实际速度受网络和镜像服务影响，不能保证每次相同。

## 面板功能

上传/拖拽参考图片、音频和视频，预览素材，填写提示词并选择分辨率、比例、整数时长和 PE 开关。打开 PE 后直接提交，后台先改写再继续生成；关闭 PE 直接使用输入文本。支持历史任务详细参数和复用、排队/阶段进度、耗时及单任务中断。超分可输出 2160p，这是独立后处理，不表示 H3 原生生成 2160p。

初次下载未完成时面板展示下载进度并阻止生成。失败可查看原因、点击重试。参考限制及实际可用设置以面板校验和随包工作流为准。

## 常见问题

**下载慢或失败？** 先区分 GitHub 运行环境下载和模型下载。GitHub 环境分卷会跳过已校验文件，未完成的分卷尝试续传；校验失败则重新下载；模型则支持分块续传。模型日志在 `/root/autodl-tmp/h3/bootstrap/download.log`，状态在同目录 `status.json`。不要通过关闭校验来继续安装。

**服务器连不上 GitHub？** 需要可用的服务器出网路径。安装脚本不会自动创造 VPN；必要时先在服务器配置可用代理。模型下载器刻意清除通用代理环境并使用国内镜像。日常 EXE 可桥接本机可用代理，Windows 没有代理时无法凭空提供外网连接。

**安装中断后提示已有安装？** 为防误覆盖，半成品安装需要先检查 `/opt/h3-suite` 和 `/opt/h3-python`。不要直接删除已有工作流；参见 Agent 部署说明。模型下载中断不属于此情况，重新连接可继续。

**验证范围？** 随包工作流在新实例通过真实 PE→视频生成与 2160p 超分测试，保留原音轨。新增部署入口经过语法、下载逻辑及校验测试；仍需在新的空白实例和 Windows 真机完成端到端验收。技术通过不保证每次视频创作效果。
