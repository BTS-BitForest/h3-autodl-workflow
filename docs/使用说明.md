# H3 集成工作流

Windows 控制端：下载根目录 `/工具包/H3控制端.zip`，完整解压后运行 H3Launcher.exe，输入本实例 SSH 命令和密码。首次连接核对主机指纹。

服务自动启动：面板固定127.0.0.1:8190，ComfyUI固定127.0.0.1:8188。通过SSH连接访问，不暴露未经认证的ComfyUI公网端口。命令行启动：

```
/opt/h3-suite/venv/bin/python /opt/h3-suite/scripts/launch_session.py
```

该命令输出一次性面板登录票据，不要公开转发。当前用户自己的接口密钥在数据盘 `/root/autodl-tmp/h3/gateway/state/token.txt` 首次启动时随机生成，镜像不预置它。

程序、工作流和模型下载清单在/opt/h3-suite。数据盘/root/autodl-tmp/h3保存模型、上传素材、视频、任务数据库和日志。必要模型及配套文件约81.46GiB，建议数据盘至少100GiB空闲，另留成片空间。系统镜像不内置数据盘内容；首次启动会自动下载，面板显示进度和总速度。

可用的同版模型优先魔搭，HF镜像备用，官网最后回退；部分LoRA只有HF镜像。每个文件固定版本、大小和SHA256，下载支持续传、失败重试与最终校验。首次下载完成前不能提交生成。

工作流包含H3 FL2VA/Ref2VA、现有LoRA/PDD/Turbo预设、Qwen3.5-4B PE、RealESRGAN视频超分。PE默认启用，提交后自动排队改写、预检、生成；可关闭并按原文提交。支持素材拖拽、预览、历史复用、耗时、阶段进度及单任务中断。非24fps参考视频自动生成24fps副本，原素材保留。PE和视频串行共用显存锁。技术生成完成不代表画面、声音和对白均通过人工验收。

DSH：`dsh`，默认直连DeepSeek。Codex：`codex`，通过本机网络路由选择可用连接。没有预置账号或API密钥，请用户自行登录。VS Code需要用户自行安装对应扩展，服务器提供DSH通用路径设置。控制端启动器内置网络桥接，关闭即断开；服务器或Windows必须实际存在可用网络，程序不会凭空提供VPN。

镜像内容审计：`/opt/h3-suite/venv/bin/python /opt/h3-suite/scripts/audit_release.py`。程序依赖许可保留在各组件目录，模型来源/版本/哈希记录在bootstrap/models.json。
